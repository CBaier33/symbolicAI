# River Crossing Puzzle using Symbolic AI

As part of the Spring 2025 CSCI 470 Machine Learning and Artifical Intelligence course at Ave Maria University, our group developed a solution to the classic river crossing logic puzzle using Prolog. 

Through the use of this declarative language, the prblem is solved by giving the rules of the environment to specify desired output, without instructing the program how to solve the problem directly. 


Please watch the video listed in the description for a demonstration and further explanation.
